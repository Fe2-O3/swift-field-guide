Swift Field Guide

Eighteen species of hard-won Swift knowledge, consolidated from the two most-starred Swift agent-skill packs on GitHub (twostraws and AvdLee, both MIT), merged, de-duplicated, and brought current — for Claude Code, Codex, OpenCode, and any agent that reads SKILL.md.

Language

Class Linguus Swiftus — the core tongue

01

write-swift

Lingua moderna

How to write modern Swift well: value types, Swift 6 data-race safety, @concurrent, actors, protocols and generics, API design, performance and ARC, macros.

Habitat: every file an agent touches.

02

swift-concurrency

Acta parallelis

Tasks, actors, @MainActor, Sendable, data races, cancellation, TaskGroup patterns, Swift 6 migration — plus concurrency code review. 18 reference files, one router.

Diets exclusively on compiler warnings.

03

swift-style

Forma elegans

Conventions for clean, readable Swift: formatting, naming, organization, idiomatic patterns.

Small range, constant presence.

UI

Class Visualis — what the user touches

04

swiftui

Velox declarativa

The flagship. Writing, reviewing, refactoring SwiftUI: state management, gesture composition, adaptive layout, navigation, architecture choice (MVVM vs TCA vs vanilla), Liquid Glass — plus Instruments .trace capture and analysis for hangs and hitches. Merged from five prior skills; ~30 reference files.

Where two merged sources disagreed, it says so — no false consensus.

05

ios-hig

Directiva humana

Human Interface Guidelines compliance: accessibility, Dynamic Type, dark mode, 44pt touch targets, animation and haptics, permission flows.

The difference between an app and an intruder.

06

haptics

Tactus vibrans

UIFeedbackGenerator and Core Haptics patterns for confirmations, errors, and custom tactile experiences.

Felt, never seen.

Platform

Class Platformus — the terrain itself

07

ios-26-platform

Platforma vitrea

iOS 26 features: Liquid Glass, new SwiftUI APIs, WebView, Chart3D — with backward compatibility discipline for iOS 17/18.

Migratory: returns each September with new plumage.

08

localization

Lingua multiplex

String Catalogs, pluralization, right-to-left layout, and modern i18n workflows.

Speaks every locale; hardcodes nothing.

Data

Class Memorius — where state goes to persist

09

swift-data

Memoria persistens

Core Data, SwiftData, SQLiteData, and GRDB: stack setup, threading, migrations, CloudKit sync — and, rarest of all, knowing which framework to pick. Merged from four skills that used to fight over the same territory.

Four species, one range, zero turf wars.

Testing

Class Probatoris — the skeptics

10

swift-testing

Probatio rigorosa

@Test, #expect, #require, traits, parameterized tests, parallel execution and isolation — and full XCTest migration guidance.

Believes nothing until #expect says so.

Diagnostics & Performance

Class Medicus — field surgery

11

swift-diagnostics

Medicus diagnosticus

Decision trees for NavigationStack bugs, build failures, and memory leaks. Root cause in minutes, not hours. Mandatory first checks before any code changes.

80% of "mysterious" issues are documented patterns.

12

xcode-build

Aedificium celeris

The single entry point for build-speed work: benchmark clean/incremental builds, diagnose slow type-checking, audit settings and script phases — and prove the win with before/after numbers.

No fix without a measurement.

13

spm-build-analysis

Arbor dependentiarum

SPM dependency graphs, package plugins, module variants, CI build overhead, and modularization strategy.

Lives in the shadow of long resolution logs.

14

swift-networking

Connexio retis

Network.framework: NWConnection, UDP/TCP patterns, structured-concurrency networking, and migrating off raw sockets and URLSession streams.

Handles transitions: WiFi to cell, mid-flight.

18

ios-simulator-skill

Simulatio domita

29 production-ready scripts for simulator testing, builds, and automation: semantic UI navigation, accessibility checks, simulator lifecycle — tuned for AI agents with minimal token output.

Vendored from Conor Luddy's MIT original, trimmed for daily use.

Ecosystem

Class Sym biotae — lives with the rest

15

composable-architecture

Reducer compositus

TCA in practice: @Reducer, Store, Effect, TestStore, reducer composition, effect handling, TCA navigation.

Flocks with swiftui; respects its airspace.

16

storekit

Mercator digitalis

StoreKit 2: subscriptions, consumables, non-consumables, .storekit configuration testing, StoreManager architecture, transaction verification.

Testing-first. No live-transaction gambles.

17

generating-swift-package-docs

Documenta ex nihilo

On-demand API documentation for unfamiliar Swift package dependencies — for those import statements nobody documented.

Feeds on mystery imports.

Start with four.

Most Swift work an agent does is covered by write-swift, swiftui, swift-concurrency, and swift-diagnostics. Adopt the rest as your project needs them.
